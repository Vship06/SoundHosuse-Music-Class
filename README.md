# SoundHouse React + Tailwind

Multi-page, responsive music-school website prototype built with React, Vite, Tailwind CSS v4, React Router and lucide-react.

## Pages
- `/` — Landing page with interactive instrument explorer, schedule, FAQ and CTA.
- `/classes` — Dedicated classes page with instrument filters and class schedule.
- `/teachers` — Dedicated teachers page with teacher profiles and trial CTA.

## Interactions
- Client-side routing between pages
- Interactive instrument selection
- Class filtering
- Teacher profile modals
- FAQ accordion
- Multi-step trial booking modal
- Dynamic monthly pricing for In-person / 1:1 / Online
- Booking confirmation state
- Responsive mobile navigation

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Vercel
Deploy from GitHub or the project folder.
Framework preset: Vite
Build command: `npm run build`
